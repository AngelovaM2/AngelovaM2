## Hi, I am Mariana 👋

I am a Computer Science and Engineering graduate from Eindhoven University of Technology (2025). I enjoy projects where my code has to work with something real, like sensors, robots or live data, and I really like building the interfaces people actually use.

🌐 **Portfolio:** [AngelovaM2.github.io](https://AngelovaM2.github.io), with videos and photos of my projects and what my part in each of them was.

### Projects you can find here

- [**Blind-spot warning device**](https://github.com/AngelovaM2/blind-spot-bike-device): GPS, LiDAR, OLED screen and sound warnings for a bicycle, on an ESP32 (C++/Arduino)
- [**Sorting robot simulation**](https://github.com/AngelovaM2/sorting-robot-simulation): a Webots copy of a disc-sorting robot, with a Java controller and Blender models
- [**MetApocalypse**](https://github.com/AngelovaM2/metapocalypse-unity-game): a logic gate puzzle, character and UI for a Unity game (C#), plus my pixel art
- [**Forsaken**](https://github.com/AngelovaM2/forsaken-unity-game): character, combat and health scripts for my first Unity game (C#)
- [**GeoTreasure**](https://github.com/AngelovaM2/geotreasure-android-app): screens and puzzle pages for a geocaching app (Java, Android)

My bachelor final project, the back end of a digital twin platform (Python, FastAPI, MQTT, PostgreSQL, Docker), belongs to the client, so its code is not public. You can read about it on my portfolio.
